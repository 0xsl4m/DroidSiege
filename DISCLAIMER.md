# ⚠️ Legal & Safety Disclaimer

**DroidSiege is an *intentionally vulnerable* Android application built for security education, training, and research.**

## Purpose

DroidSiege exists to help security professionals, students, mobile developers, and
enthusiasts learn how mobile vulnerabilities look, how they are exploited, and — most
importantly — how they are fixed. It is aligned with the
[OWASP MASVS](https://mas.owasp.org/MASVS/), the
[OWASP MASTG](https://mas.owasp.org/MASTG/), and the OWASP Mobile Top 10 (2024).

## Rules of Use

- **Only install and test DroidSiege on devices/emulators you own or are authorized to use.**
- **Do NOT install it on a personal daily-driver device.** Use a dedicated emulator or a
  spare test device. The app deliberately stores data insecurely, exposes components, and
  communicates insecurely.
- **Do NOT deploy the backend to a public/production server.** Run it locally or inside an
  isolated lab network. It is intentionally insecure.
- **Do NOT reuse any code, pattern, or configuration from this project in real software.**
  Every "vulnerable" branch here is an example of what *not* to do.
- The techniques you learn here are for **authorized testing, CTFs, and defensive research
  only.** Using them against systems you do not own or lack permission to test is illegal.
